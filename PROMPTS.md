```text
[STRICT MODE — Unattended Cloud Run]

Cloud VM. No LAN/NAS. No secrets. Do not rely on local daemons (e.g., Ollama). Follow repo `AGENTS.md`.

This is a **T-task**:
- **Top bar:** scan broadly for panic/perf risk patterns.
- **Stalk:** harden ONE module deeply to materially improve robustness and maintainability.

Hard constraints:
- Choose exactly ONE stalk module.
- Max 6 files changed total (including tests).
- Avoid feature sprawl; focus on error handling + robustness.

Top bar (broad scan — do not edit yet):
1) Scan for panic risks and perf smells:
   - `unwrap()` / `expect(...)` in non-test code paths
   - high clone density (`.clone()`) where borrowing could work

   - Use repo search tools to find unwrap/expect/clone usage.
   - Optionally run clippy (non-fatal) to see baseline warnings.
```
